一、U-Boot 中的 Host 程序

U-Boot 的构建系统采用与 Linux 内核相似的 Kbuild 架构，这使得 U-Boot 的配置和编译过程更灵活和自动化。构建系统主要由 Makefile 脚本、Kconfig 配置语言和一系列 host 程序组成，它们共同协作完成从源码到可执行镜像的转换。

Host 程序是指在编译主机上本地执行的程序，它们不参与 U-Boot 运行时环境的构建，而是负责处理各种构建前置任务。这些程序通常由C语言编写，并在构建过程的早期被编译成本地可执行文件。它们在 U-Boot 项目中的位置通常位于 scripts/、tools/ 等目录下。
